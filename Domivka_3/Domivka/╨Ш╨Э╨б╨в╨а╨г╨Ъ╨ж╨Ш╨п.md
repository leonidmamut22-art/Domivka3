# Домівка — Telegram-бот аренды жилья. Инструкция для новичка

Что в архиве:
- `bot/` — сам бот (самостоятельный, своя база данных, сайт ему не нужен)
- `start.bat` — запуск на Windows двойным кликом
- `start.sh` — запуск на Mac/Linux
- `install_service.sh` — установка на сервер, чтобы бот работал 24/7
- `website/` — сайт-витрина (отдельный проект, необязательный)
- `data/` — сюда бот сам сохраняет базу `domivka.db` и копии `backups/`

Новые функции (оплата, залог, продвижение, отзывы в обе стороны) описаны в частях 6–8.
**Самое новое (часть 9):** оплата напрямую между гостем и хозяином (без ваших денег и ФОП), верификация, акты, долгосрочная аренда, удобства, карта/радиус, сравнение, защита от краденых фото.

Бот интерфейсом говорит по-украински (рынок: Украина, гривна). Тексты можно поменять в `bot/bot.py`.

## ЧАСТЬ 1. Запуск бота на вашем компьютере (15 минут)

### Шаг 1. Создайте бота в Telegram
1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите Start.
2. Отправьте команду `/newbot`.
3. Он спросит название: напишите, например, `Домівка`.
4. Потом имя пользователя, оно должно заканчиваться на `bot`: например `domivka_rent_bot`.
5. BotFather пришлёт **токен**: длинная строка вида `123456789:AAH...`. Скопируйте её и никому не показывайте. Это пароль от бота.

### Шаг 2. Узнайте свой Telegram ID (чтобы получить админ-панель)
1. Найдите бота **@userinfobot**, нажмите Start.
2. Он ответит числом (`Id: 123456789`). Это ваш ID, запомните число.

### Шаг 3. Установите Python (один раз)
1. Откройте python.org/downloads, скачайте Python 3.11 или новее.
2. При установке **обязательно поставьте галочку «Add python.exe to PATH»** внизу первого окна, затем Install Now.

### Шаг 4. Запустите
1. Распакуйте архив `Domivka.zip` в любую папку (правая кнопка → «Извлечь всё»). Не запускайте бота из-под архива.
2. Дважды кликните **start.bat**.
3. Первый раз он 1–2 минуты ставит нужное, потом спросит два значения:
   - вставьте токен из шага 1 и нажмите Enter (вставка: правая кнопка мыши в окне);
   - вставьте свой ID из шага 2 и нажмите Enter.
4. Когда увидите строку «Бот @... запущено», всё работает. **Окно не закрывайте**: пока оно открыто, бот отвечает.
5. Откройте своего бота в Telegram → `/start`.

Следующие запуски: просто двойной клик по start.bat. Токен больше вводить не нужно (он сохранён в файле `.env`).

### Шаг 5. Проверьте, что всё работает (обязательно)
Нужны два аккаунта Telegram (второй: телефон друга или второй профиль).
1. Аккаунт А: `/start` → «Здаю житло» → поделитесь номером → «➕ Нове» → пройдите вопросы → добавьте фото → «Опублікувати».
2. Аккаунт Б: `/start` → «Шукаю житло» → найдите объявление → «Забронювати» → выберите даты → «Надіслати заявку».
3. Аккаунту А придёт заявка с кнопками. Нажмите «Підтвердити»: Б получит контакты.
4. Попробуйте забронировать те же даты: они будут отмечены ❌.
5. Нажмите «Запитати» и напишите сообщение: оно придёт второй стороне.
6. Аккаунт А: «🛡 Адмін-панель» → статистика, скарги, розсилка, експорт CSV.

## ЧАСТЬ 2. Как сделать, чтобы бот работал 24/7 при выключенном компьютере

На обычном компьютере бот работает только пока он включён. Для постоянной работы нужен сервер (VPS). Варианты:

**Вариант А. Oracle Cloud «Always Free» (бесплатно, но с нюансами).**
Я проверил информацию в интернете: бесплатный тариф существует, но условия менялись в 2026 году (лимит бесплатных ARM-серверов снижен), нужна банковская карта для проверки личности (деньги не списываются), в популярных регионах бывает «Out of capacity», а простаивающие серверы Oracle может останавливать. Перед регистрацией проверьте актуальные условия на oracle.com/cloud/free. Для этого бота хватает самого маленького сервера (1 ГБ памяти).

**Вариант Б. Google Cloud «e2-micro»** (бесплатный сервер в американских регионах, нужна карта). Условия тоже проверьте на сайте Google.

**Вариант В. Платный VPS за 3–5 долларов в месяц** (Hetzner, Contabo и т.п.). Самое надёжное, если проект станет рабочим.

**Вариант Г. Домашний мини-компьютер** (Raspberry Pi или старый ноутбук, который всегда включён). Бесплатно, но зависит от вашего интернета и света.

Бесплатные «спящие» хостинги (Render, Replit и подобные) для этого бота не подходят: они засыпают и бот перестаёт отвечать.

### Установка на сервер (одинаково для вариантов А, Б, В)
Вам нужен сервер с Ubuntu 22.04 или 24.04 и вход по SSH. При создании сервера провайдер покажет IP-адрес и даст ключ или пароль.

1. Подключитесь: в Windows откройте PowerShell и введите `ssh ubuntu@IP_АДРЕС` (у Oracle пользователь обычно `ubuntu`, ключ добавляется параметром `-i путь\к\ключу`).
2. Загрузите архив на сервер. На своём компьютере (в PowerShell, в папке с архивом):
   `scp Domivka.zip ubuntu@IP_АДРЕС:~`
3. На сервере выполните по очереди:
   ```
   sudo apt-get install -y unzip
   unzip Domivka.zip -d Domivka
   cd Domivka
   bash install_service.sh
   ```
4. Скрипт спросит токен и ваш ID, поставит всё сам и запустит бота как службу. Она стартует после перезагрузки и перезапускается при сбое.
5. Закройте SSH. Бот работает сам.

Полезные команды на сервере:
- Логи (что происходит): `sudo journalctl -u domivka -f` (выход: Ctrl+C)
- Перезапуск: `sudo systemctl restart domivka`
- Остановка: `sudo systemctl stop domivka`

Важно: если бот уже работает на сервере, не запускайте его одновременно на своём компьютере с тем же токеном. Telegram разрешает только один запуск, второй будет выдавать ошибку.

### Перенос с компьютера на сервер с данными
Скопируйте на сервер папку `data` (в ней `domivka.db`) вместе с файлом `.env`. Тогда объявления и пользователи сохранятся.

## ЧАСТЬ 3. Настройки (файл `.env`, открывается Блокнотом)

| Параметр | Что делает |
|---|---|
| `BOT_TOKEN` | токен бота (обязательно) |
| `ADMIN_IDS` | ID админов через запятую; у них появляется «Адмін-панель» |
| `GEMINI_API_KEY` | необязательно: ключ Google Gemini (aistudio.google.com → Get API key) для умного понимания запросов и красивых описаний. Без ключа бот работает на встроенных простых правилах |
| `SITE_URL` | необязательно: адрес сайта, в меню появится кнопка «Сайт» |
| `REQUIRE_APPROVAL` | `1` — новые объявления сначала проверяете вы (кнопки «Схвалити / Заблокувати» придут вам в Telegram). `0` — публикуются сразу |

После изменения `.env` перезапустите бота.

## ЧАСТЬ 4. Что умеет бот

**Для гостя:** поиск по городу, району, цене, типу (за ночь / за месяц), сортировка (дешёвые, с рейтингом, новые); умный поиск обычным текстом; карточка с фото, рейтингом, сравнением цены со средней по городу; календарь с занятыми датами; бронирование; чат с хозяином; обране; кнопка «Поделиться» оголошенням; скасування бронювання; напоминание накануне заезда; запрос отзыва после проживания.

**Отзывы и доверие:** отзыв могут оставить только гости с подтверждённым и завершённым проживанием (подделать нельзя). Рейтинг жилья, профиль хозяина (рейтинг, подтверждённый номер, число проживаний, последние отзывы), значок «🏅 Супергосподар» (рейтинг от 4.7 и минимум 3 отзыва).

**Для арендодателя:** пошаговое создание оголошення (до 6 фото, описание от AI), редактирование цены за ночь и за месяц, знижки, названия, описания, фото; закрытие дат (когда живёте сами); скрыть/показать; видалити; заявки с кнопками; статистика (просмотры, бронирования, доход, рейтинг).

**Для вас (админ):** статистика; скарги от пользователей на оголошення; модерация; блокировка оголошень; бан пользователей (его оголошення блокируются); розсилка всем; экспорт CSV (пользователи, оголошення, бронирования, отзывы). Все контакты проверены через номер Telegram. Копия базы делается автоматически каждый день в `data/backups` (хранятся последние 14).

## ЧАСТЬ 6. Оплата, залог и выплаты хозяину (старые режимы)
> ⚠️ Описанные здесь режимы `manual` и `telegram` держат деньги гостей у платформы (у вас). Это то, чего вы хотели избежать. Теперь по умолчанию работает режим `direct` из части 9; части 6 нужна, только если вы сознательно выберете старые режимы.

### Как это работает (против «забронировал и не пришёл»)
1. Гость отправляет заявку на даты. Хозяин подтверждает (или бронь «Миттєве бронювання»: без ожидания хозяина).
2. Бот присылает гостю счёт на **залог** (`DEPOSIT_PERCENT`, по умолчанию 30%, можно 100%). На оплату есть `PAY_WINDOW_HOURS` часов. Не оплатил: бронь сама отменяется, даты снова свободны. Хозяин не ответил за `HOST_REPLY_HOURS`: заявка тоже сама отменяется.
3. Деньги остаются у платформы (у вас). Адрес и инструкции заселения гость видит только после оплаты.
4. В день заезда бот спрашивает гостя «Вы заселились?». «Да» → выплата хозяину ставится в очередь. «Проблема» → выплата замораживается, вам приходит спор. Если гость молчит сутки, выплата ставится в очередь сама.
5. Вы в админке бота → 💰 Фінанси → 💸 До виплати видите сумму и реквизиты хозяина (он вводит их в меню «💳 Реквізити виплат»), переводите деньги и нажимаете «✔ Виплачено». Хозяин получает уведомление.
6. Отмена гостем не позднее чем за `FREE_CANCEL_HOURS` до заезда: залог возвращается (раздел «↩️ Повернення»). Позже: залог остаётся хозяину. Хозяин отменил оплаченную бронь: гостю возврат.

### Три режима (`PAYMENT_MODE` в `.env`)
- **off** — как раньше, без денег. Включён по умолчанию.
- **manual (рекомендую для старта, бесплатно)**: впишите в `PAYMENT_REQUISITES` свою карту/IBAN. Гость переводит залог, пишет в назначении код брони, жмёт «Я оплатив» и присылает скриншот. Вам в Telegram приходит чек с кнопками «✅ Оплату отримано» / «✖ Не знайшов». После вашего подтверждения бронь активна.
- **telegram** — оплата карточкой внутри Telegram. Нужен платёжный провайдер: в @BotFather → /mybots → ваш бот → Payments, выберите провайдера и получите токен (для проверки сначала берите тестового провайдера, как советует документация Telegram), вставьте в `PAYMENT_PROVIDER_TOKEN`. Какие провайдеры доступны для гривны и вашей страны, смотрите в том же меню BotFather: я это подтвердить не смог. Возврат платежа бот сам не делает: вы возвращаете в кабинете провайдера и нажимаете «✔ Повернено».

### Что важно знать
- Деньги других людей на вашей карте — это финансовая деятельность: налоги, ФОП, возможные требования к платёжным сервисам. До запуска оплаты проконсультируйтесь с бухгалтером или юристом в вашей стране. Когда пойдут объёмы, надёжнее платёжный провайдер с режимом маркетплейса (деньги делятся автоматически).
- Реквизиты хозяев лежат в `data/domivka.db` открытым текстом. Никому не отправляйте этот файл и копии из `data/backups`, ограничьте доступ к серверу.
- Комиссию задаёт `COMMISSION_PERCENT` (0 = пока бесплатно). Она вычитается из залога при выплате хозяину.

## ЧАСТЬ 7. Продвижение объявлений (новое)
Хозяин: «Мої оголошення» → объявление → «🔥 Просунути». Объявление поднимается в начало выдачи, получает значок «🔥 Топ» и попадает в раздел «🔥 Топ» главного меню.
- **Бесплатно** (по умолчанию): раз в 7 дней на `BOOST_FREE_DAYS` дней, на каждое объявление.
- **Платно**: `BOOST_PRICE_PER_DAY` больше нуля и `PAYMENT_MODE=telegram`: хозяин покупает 3, 7 или 30 дней.
- **Платно за Telegram Stars** (рекомендуется, без ФОП): задайте `BOOST_STARS_PER_DAY` больше нуля, см. часть 9.1.

## ЧАСТЬ 8. Другие новые функции
- **Отзывы в обе стороны:** гость оценивает жильё и хозяина, хозяин оценивает гостя (бот просит оценку после выезда). У гостя есть рейтинг, и хозяин видит его в заявке («👤 Профіль гостя»).
- **Миттєве бронювання:** хозяин включает для объявления, и бронь не ждёт его ответа.
- **Мінімальний термін проживання** и **адреса/інструкції** (видны только после подтверждения/оплаты): кнопки в меню объявления.
- **Підписки 🔔:** в поиске «Стежити за новими». Бот пришлёт уведомление, когда появится подходящее объявление.
- **Безопасность чатов:** до подтверждения брони телефоны и ссылки в сообщениях скрываются (защита от мошенников и обхода платформы).
- **Автоматизация:** автоотмена неотвеченных заявок и неоплаченных броней, напоминание накануне заезда, «Вы заселились?», автовыплата, ежедневная копия базы.
- **Админ:** 💰 Фінанси (удержано, к выплате, выплачено, комиссия, возвраты, споры), чеки на подтверждение, экспорт платежей.

## ЧАСТЬ 9. Как бот зарабатывает и защищает вас: оплата напрямую, доверие, долгая аренда (новое)

### 9.1. Деньги не проходят через вас (`PAYMENT_MODE=direct`, включено по умолчанию)
Бот только организует сделку и фиксирует факты. Платят гость и хозяин друг другу напрямую. Вы не принимаете чужие деньги: нет риска блокировки карты, нет ФОП и налога с чужого оборота, нет ответственности за переводы.

Хозяин сам выбирает для каждого объявления («Мои объявления» → объявление → «💳 Оплата и залог»):
- **💵 При заселении**: передоплаты нет, гость платит на месте (по умолчанию).
- **💳 Передоплата на карту хозяина**: после подтверждения заявки бот показывает гостю реквизиты хозяина, гость переводит и нажимает «Я оплатив(ла)», хозяин нажимает «Получил», бронь становится окончательной. Реквизиты видны только после подтверждения заявки. Нужна верификация хозяина (`REQUIRE_VERIFIED_HOST=1`).
- **🤝 Доверие**: проверенные гости (верификация или 2+ проживания с рейтингом от 4.5) бронируют без предоплаты, остальные платят наперёд.
- **🔐 Залог за ущерб**: сумма задаётся в объявлении, передаётся хозяину напрямую при заселении и возвращается при выезде по акту.

Защиты: если гость заявил оплату, бронь не отменяется автоматически; хозяину приходит напоминание через 5 часов, а вам сигнал, если он молчит больше суток. Споры решаются по доказательствам (акты, фото, чат), см. 9.3. Деньги бот не двигает.

Как зарабатываете: **продвижение объявлений за Telegram Stars** (`BOOST_STARS_PER_DAY`, например 5 звёзд в сутки). Stars работают без ФОП и эквайринга. Вывод Stars: минимум 1000 Stars, звёзды доступны через 21 день после получения, обмен на TON через Fragment (там может понадобиться верификация). Условия Telegram меняются, проверяйте в настройках бота. Дальше можно добавить платную подписку для хозяев (статистика, приоритет). Когда доход станет регулярным, откроете ФОП и будете платить налог уже с реальной прибыли; для налоговых вопросов нужен бухгалтер.

### 9.2. Верификация и антимошенничество
- **🛡 Верификация** (меню у всех): фото документа + селфи → приходит вам в админ-панель → «🛡 Верификации» → ✅/✖. После решения фото **удаляются из базы бота**. Верифицированные получают бейдж ✅.
- **Дубликаты фото:** бот сравнивает «отпечатки» фото объявлений разных хозяев. Совпадение (украденные фото) → объявление уходит на модерацию, вам приходит уведомление.
- **Подозрительная цена:** если цена вдвое ниже средней по городу, в карточке предупреждение для гостя.
- **Чаты:** до подтверждения брони телефоны и ссылки скрыты. Предупреждения «не платите вне бота» встроены в сообщения об оплате.
- **Претензии и попытки обмана:** хозяин или гость подаёт претензию («📋 Угоды й акти» → «⚠️ Претензія»). Вам приходит претензия вместе с актами и фото. «Обоснована» даёт нарушителю предупреждение, после 3 предупреждений бот предлагает блокировку.

### 9.3. Акты заселения и выезда
В день заезда бот просит обе стороны составить акт: фото состояния, показания счётчиков (свет, вода, газ), заметки (передача ключей и залога). Акт действует, когда подтвердили обе стороны; любое изменение сбрасывает подтверждения. При выезде бот считает расход по разнице показаний. Хозяин отмечает «🔓 Залог возвращён».

### 9.4. Долгосрочная аренда (от `LONG_TERM_DAYS`, по умолчанию 28 ночей)
После подтверждения брони бот создаёт «угоду»: 
- **📄 Договор:** файл .html (откройте в браузере, распечатайте или сохраните как PDF). Это шаблон-основа из данных брони, а не юридическая консультация: вставьте паспортные данные и подпишите, для длинных сроков проконсультируйтесь с юристом или нотариусом. Обе стороны вносят ФИО и жмут «✅ Погоджую умови».
- **🧾 Ежемесячные платежи:** в день платежа бот выставляет аренду, гость переводит напрямую и жмёт «Сплатив», хозяин подтверждает, и обе стороны получают квитанцию. Через 3 дня без оплаты приходит напоминание.
- **🔢 Лічильники и коммуналка:** хозяин задаёт тарифы («🧾 Тарифи» в объявлении: свет, вода, газ), гость присылает показания, бот считает (текущее − прошлое) × тариф, хозяин подтверждает расчёт, дальше оплата как у аренды.

### 9.5. Удобство для гостей
- **🤖 AI-помощник:** пишете как человек («2 комнаты на месяц в центре до 15000, с генератором и собакой»). Удобства распознаются и без ключа Gemini. С ключом: ответы на вопросы по конкретному жилью («🤖 AI про житло») и совет по сравнению вариантов.
- **🏷 Удобства, важные для Украины:** свет без перебоев (генератор/EcoFlow), укрытие рядом, интернет/Starlink, автономное отопление, вода/бойлер, можно с животными, принимаю ВПО, парковка, лифт и др. Хозяин отмечает их, гость фильтрует.
- **📍 Рядом со мной и радиус** (1/3/5/10 км, сортировка по расстоянию) и **🗺 на карте**. Гостям показывается только приблизительное место (до ~1 км), точное остаётся адресом после подтверждения.
- **⚖️ Сравнение** до 3 вариантов в одной таблице.
- **💡 Подсказка цены** хозяину при создании объявления (средняя по городу).

### 9.6. Обновление существующей установки
Просто замените папку `bot/` (и `.env.example`) новой версией, свой `.env` и папку `data/` оставьте. База обновится сама при запуске (колонки и таблицы добавляются, данные не теряются). `start.bat` / `start.sh` сами доустановят Pillow. ## ЧАСТЬ 10. Mini App: полноценное приложение внутри Telegram (обновлено)

Mini App теперь умеет всё главное, что нужно гостю и хозяину, без перехода в чат. Бот и Mini App работают с одной базой, поэтому заявка из приложения сразу приходит хозяину в бот, а статус бронирования виден в обоих местах.

**Для гостя:**
- Поиск с умной строкой («2 комнаты на месяц в центре до 15000, с генератором»), быстрые фильтры, окно «Фильтры» (город, район, цена, комнаты, гости, удобства, сортировка), «📍 Поблизости», избранное.
- Карточка жилья: галерея, рейтинг, отзывы, хозяин, удобства, способ оплаты.
- **Бронирование прямо в приложении:** календарь с занятыми датами (зачёркнуты), выбор гостей, живой расчёт суммы, скидок, предоплаты и остатка. Кнопка «Надіслати заявку» или «Забронювати» (для миттєвого бронювання).
- Если нужна предоплата, реквизиты хозяина и код платежа показываются сразу, кнопка «✅ Я оплатив(ла)» отправляет хозяину запрос на подтверждение.
- Вкладка «Бронювання»: статусы, оплата, отмена, написать хозяину, оставить отзыв звёздами.
- **Чаты прямо в приложении** (вкладка «Чати»): написать хозяину из карточки жилья, быстрые ответы, красные бейджи непрочитанных; сообщения параллельно приходят в бота. Пока бронь не подтверждена, телефоны и ссылки в сообщениях скрываются.
- **Карта** («🗺 Мапа» среди фильтров): цены прямо на карте, переход к карточке, поиск «📍 Поруч».
- **Сравнение** до 3 вариантов (кнопка ⚖️ на фото), фильтр «⚡ Миттєво», подписка «🔔 Стежити» на новые объявления по вашим фильтрам.

**Для хозяина (вкладка «Кабінет»):**
- Заявки с кнопками «Підтвердити / Відхилити», подтверждение полученной предоплаты, отмена брони.
- Список объявлений: статус, просмотры, бронирования, быстрое изменение цены, скидки, минимума ночей, миттєвого бронювання, скрытие объявления.
- **Создание объявления с фото** (до 6, сжимаются на телефоне), удобствами, способом оплаты и приватным адресом; кнопка «✨ написать за меня» (описание от AI).
- Расположение на карте: отметка при создании объявления и позже; чат с гостем из заявки.
- Подсказки: подтвердить номер, пройти верификацию, указать карту (открывают нужный раздел бота).

**Что остаётся в боте (так удобнее):** уведомления, акты заселения и выезда, договор и график платежей для длительной аренды, верификация документами, продвижение за Telegram Stars, админ-панель. В приложении есть кнопки быстрого перехода в нужное место бота.

**Первый вход.** Приложение само предложит выбрать роль, а номер телефона запросит перед первым бронированием или публикацией (Telegram подтверждает его сам).

**Как запустить (теперь без ручных тоннелей).** Ничего не нужно запускать отдельно: ни `localhost`, ни PowerShell, ни `cloudflared`.
1. Запустите бота как обычно (`start.bat`).
2. Бот сам запускает веб-сервер Mini App, сам скачивает `cloudflared` (один раз, около 40 МБ, в папку `data/bin`), сам открывает публичный https-адрес и сам ставит кнопку «Домівка» в чате с ботом. В окне бота появится строка «📱 Mini App готовий: https://…».
3. Откройте чат с ботом и нажмите кнопку **«Домівка»** рядом с полем ввода (или «📱 Відкрити Домівку» в меню, или команду `/app`).
Первый запуск занимает 1–2 минуты (скачивание). Потом около 10 секунд.

Важно знать:
- **Адрес бесплатного тоннеля меняется при каждом перезапуске бота.** Это нормально: кнопка «Домівка» обновляется сама. Старые сообщения с кнопкой «Відкрити додаток» перестанут открываться: нажмите `/app` и получите свежую кнопку.
- Открывать Mini App нужно **именно кнопкой «Домівка» / `/app` в боте**. Если вставить адрес в браузер или нажать на него как на обычную ссылку, Telegram не передаёт данные входа, и вы увидите «Відкрити в Telegram». Это не ошибка, просто режим просмотра.
- Антивирус или SmartScreen в Windows иногда блокируют скачанный `cloudflared.exe`: разрешите его для папки `data\bin`. Если интернет блокирует Cloudflare, Mini App не поднимется, а бот продолжит работать как раньше.
- Постоянный адрес (не меняется): либо VPS с вашим доменом и https (впишите `WEBAPP_URL=https://ваш-домен`, автотоннель отключится), либо бесплатный именованный тоннель Cloudflare на вашем домене (нужен домен). Для простого старта это не требуется.
- Настройки в `.env` (всё необязательно): `TUNNEL=off` (отключить автотоннель), `WEBAPP=off` (выключить Mini App), `WEBAPP_PORT=8080` (порт; если занят, бот возьмёт следующий свободный), `WEBAPP_URL=https://…` (свой постоянный адрес).

**Платные «Топ»-пакеты** и Telegram Stars описаны выше (часть про заработок); они работают и в боте, и в Mini App (значок 🔥 Топ).

**Что я проверил, а что нет.** Автотестами: весь серверный API (регистрация, поиск, бронирование, занятые даты, защита от двойной брони, заявки хозяина, предоплата напрямую, отмена, отзывы, права доступа, подделка подписи Telegram) и экран приложения в имитации браузера (поиск, карточка, календарь, бронирование, мои бронирования, кабинет хозяина, онбординг). В живом Telegram и на телефоне я приложение не открывал: проверьте на своём устройстве, особенно запрос номера телефона, выбор фото и геопозицию.

**Границы.** Акты, договоры и верификация документами оформляются в боте. Карта использует бесплатные тайлы OpenStreetMap (для небольшой нагрузки этого достаточно).

**Если Mini App пишет «Відкрити в Telegram» или не показывает ваши объявления.**
1. Откройте его кнопкой «Домівка» в чате с ботом, а не по ссылке из браузера или сообщения.
2. Посмотрите окно бота: при открытии не через Telegram бот пишет «запит без підпису Telegram…», при чужом боте «підпис Telegram не збігається…».
3. Проверьте, что запущен только один экземпляр бота (одно окно) и это тот же `BOT_TOKEN`, что у кнопки.
4. Проверка связи: откройте `https://ваш-адрес/api/ping`: должен показаться `{"ok": true, "listings": N}`, где N равно числу видимых объявлений. Если оно меньше, чем вы ожидаете, объявление может быть на модерации, скрыто или заблокировано.
5. Нажмите «Спробувати знову» в приложении или `/app` для новой кнопки.

## ЧАСТЬ 11. Клуб Домівки: рост без рекламы (новое)

Идея: каждый пользователь сам приводит новых, а у платформы это ничего не стоит. Награды не деньги: это скидки от хозяев-партнёров, бесплатное продвижение и статус.

**Клуб и бали.** Бали начисляются автоматически (и в боте, и в Mini App): друг присоединился +20 (вам) и +20 другу; подтверждённый номер +10; своё проживание +100; отзыв +20; хозяину за опубликованное объявление +30 и за гостя, который выехал без проблем, +50; визит в приложение +2 (за 7 дней подряд +8). Рівні: 🌱 Гість → 🧭 Мандрівник (100) → 💎 Друг Домівки (300) → 👑 Амбасадор (700).

**Что дают бали.**
- С уровня «Мандрівник» гость получает **знижку Клубу** в объявлениях, где хозяин её включил (0–15%). Скидку даёт хозяин по своему желанию, платформа ничего не доплачивает, а хозяин получает постоянных гостей.
- Обмен баллов на «🔥 Топ» для объявления хозяина (60 баллов = 3 дня, 120 = 7 дней).
- Статус и место в рейтинге «Найкращі амбасадори».

**Рефералка.** У каждого есть личная ссылка `t.me/БОТ?start=r_ВАШ_ID` (кнопка «Запросити друзів» в Mini App и в боте: ⋯ Ще → 🎁 Клуб). Любая ссылка «Поділитись» (на объявление или на список желаний) автоматически содержит ссылку-приглашение, поэтому каждая отправленная ссылка приводит людей в сервис и приносит баллы автору. Защита: нельзя пригласить самого себя, бали дают только за подтверждённый номер, у одного человека не более 25 таких начислений, повторно за одно событие не начисляется.

**Что ещё удерживает людей.**
- **Вступительный экран** (3 слайда) при первом открытии, **подборки** на главной («Зі світлом», «Є укриття», «Для ВПО», «З тваринами», «З дітьми», «На місяць», «Топ», «Нові») и блок «Ви дивились».
- **Сповіщення про зниження ціни** для тех, кто добавил жильё в обране (приходят в бота с кнопкой в приложение).
- **Найближча поїздка** с обратным отсчётом и экран **«🔑 Заселення»**: адрес и инструкции (видны только после подтверждения брони), контакты хозяина, маршрут, добавление в календарь, быстрый чат; после выезда кнопка «🔁 Знову».
- **Публічний список бажань**: кнопка «Поділитись» во вкладке «Обране», друзья открывают ваш список по ссылке.
- **Для хозяина:** оценка качества каждого объявления (0–100) и конкретные советы («добавьте фото», «включите скидку Клубу»), сравнение вашей цены с рынком, число лайков и чатов, кнопка «Поділитись» с вашей реферальной ссылкой.

**Как запустить рост (что делать вам).**
1. Наберите первых 10–20 хозяев вручную (знакомые, группы Telegram вашего города) и попросите включить «знижку Клубу 5%» и добавить фото и карту.
2. Попросите каждого хозяина разослать свою ссылку «Поділитись» клиентам: она ведёт в бота и приносит ему баллы.
3. Регулярно смотрите админ-панель бота (кто приглашает больше всех) и поощряйте топ-амбасадоров вручную: личное «спасибо» или бесплатный «Топ».

**Честно о границах.** Рост от этого сам не включится: рефералка работает, когда есть что показывать (объявления) и кому делиться. Скидки Клубу появятся только там, где хозяин их включил. Бали не имеют денежной стоимости и не выплачиваются, но правила бонусных программ могут отличаться по странам, поэтому при масштабировании проконсультируйтесь с юристом. Начисления проверены автотестами, живой Telegram и реальных людей я не проверял.

## Если что-то не работает
- **Окно закрывается сразу или пишет «Python не найден»:** переустановите Python с галочкой PATH.

- **Забыли токен:** в @BotFather → /mybots → ваш бот → API Token.
- Любую ошибку можно скопировать из окна/логов и прислать мне: я исправлю.

## Честно о границах

## ЧАСТЬ 10. Версія 3: новий дизайн, імпорт, Pro і заробіток

**Дизайн Mini App.** Мінімалізм у дусі Airbnb: великі фото з крапками й стрілками, плаваюча навігація з рухомим індикатором, живий заголовок, плавні анімації, темна тема з Telegram. Свайпи тепер працюють і пальцем, і мишкою; теги й сердечко більше не «їдуть» разом із фото.

**Імпорт оголошення за посиланням.** Кабінет → «+ Оголошення» → вставте посилання на *своє* оголошення (OLX, DOM.RIA, сайт агентства), поставте галочку «Це моє», і форма заповниться сама разом із фото. Це швидкий спосіб наповнити сервіс: просіть рієлторів і господарів переносити оголошення за 30 секунд. Сервер забороняє звернення до внутрішніх адрес (захист від SSRF), ліміт 15 імпортів на годину на користувача, усі фото проходять перевірку на дублікати.

**Монетизація (усе через Telegram Stars, без ФОП):**
1. **Домівка Pro** (Кабінет → картка Pro): до 50 оголошень замість 3, значок 💎, знижка на «Топ». Налаштування: `FREE_LISTINGS`, `PRO_LISTINGS`, `PRO_STARS_30`, `PRO_STARS_90`, `PRO_BOOST_DISCOUNT`.
2. **Платне «Топ»** прямо в Mini App (кнопка «🔥 Просунути»): задайте `BOOST_STARS_3/7/30`.
3. Далі за зростання: комісія з броні (`COMMISSION_PERCENT`), реклама від партнерів (клінінг, меблі), платна верифікація.
У «Адмін-панель → Статистика» тепер видно активні Pro-підписки та зароблені Stars (всього й за 30 днів).

**Що важливо знати.** Парсинг чужих сайтів без дозволу порушує їхні правила, тому в боті реалізовано імпорт власного оголошення за посиланням. Виведення Stars: мінімум 1000 Stars, актуальні умови перевіряйте в Telegram.
