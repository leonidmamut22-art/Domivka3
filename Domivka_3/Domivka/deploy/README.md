# Постійний безкоштовний сервер Domivka

Підготовлено для Ubuntu/Debian VM. Код не створює хмарні ресурси й не підключає оплату.

## Що потрібне
- Ваш акаунт Oracle Cloud і доступна VM з позначкою Always Free eligible. Реєстрацію, перевірку особи/картки та прийняття умов власник проходить сам.
- Окремий hostname для цього бота. Можна взяти безкоштовний піддомен DuckDNS та прив'язати його до IP VM. Домен не має вести до іншого бота.
- У правилах Oracle VCN і локального firewall мають бути дозволені вхідні TCP 80/443. SSH 22 відкривайте лише для своєї IP. Не вимикайте firewall цілком.
- BOT_TOKEN вводиться приховано на сервері. Не надсилайте токен або SSH private key у чат.

## Встановлення

Завантажте актуальну перевірену збірку на VM. З папки Domivka_3/Domivka запустіть:

    sudo bash deploy/install.sh main domivka-example.duckdns.org 8088

Замініть приклад hostname власним. Скрипт встановлює Python, Caddy і службу domivka@main. Код лежить у /opt/domivka/main, база — /var/lib/domivka/main/domivka.db, приватна конфігурація — /etc/domivka/main.env (права 0600). Служба працює від окремого користувача, стартує після перезавантаження VM та перезапускається після аварійного завершення.

    sudo systemctl status domivka@main
    sudo journalctl -u domivka@main -f
    curl https://YOUR-HOST/api/identity

Бот відмовиться встановлювати кнопку, якщо HTTPS-адреса належить іншому боту. Перевірте bot_id і bot_username в /api/identity. Не публікуються токен чи ключі.

## Перенесення робочої бази

Перед перенесенням зробіть узгоджену SQLite backup-копію, або зупиніть старий процес і скопіюйте базу разом із актуальним WAL. Не копіюйте лише domivka.db із працюючого процесу. Зупиніть службу на VM, помістіть backup у /var/lib/domivka/main/domivka.db, надайте власника domivka:domivka і права 0600, потім запустіть службу. Не запускайте два polling-процеси з одним BOT_TOKEN.

Після перевірки VM зупиніть старий локальний бот. На комп'ютері більше не потрібно натискати Start Bot.

## Два різні боти

Кожному потрібні власні токен, hostname, порт і база. Другий інстанс можна встановити як інше ім'я на порт 8089. Не використовуйте один WEBAPP_URL для двох ботів. Порт більше не змінюється мовчки, якщо зайнятий: замість випадкового підключення до сусіднього сервісу буде явна помилка.

Кнопка меню налаштовується ботом після перевірки адреси. Якщо в BotFather окремо налаштовано Main Mini App / кнопку профілю, її URL потрібно також змінити на новий hostname: Bot API не змінює цю окрему конфігурацію.

## Безкоштовність і межі

Oracle Always Free має обмеження й може забирати неактивні VM; наявність вільних ресурсів залежить від регіону. Це не гарантія uptime. Не обирайте платні shapes, не оновлюйте акаунт до платного тарифу заради цього встановлення. Слідкуйте за квотами й резервними копіями.

Джерела: https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm та https://www.oracle.com/cloud/free/faq/ .
